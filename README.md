# Платформа для спортивной мафии

Рейтинги, турниры, протокол судьи, оверлей для OBS и зрительские страницы. Игры и турнирная таблица сохраняются в SQLite на сервере.

## Как запустить сервер

Откройте терминал WSL или Linux в корне проекта. Проверьте, что Docker запущен и команда `docker compose version` работает. Если используете Docker Desktop, включите интеграцию с вашей WSL-системой.

1. Перейдите в папку деплоя и создайте `.env`, если его ещё нет.

   ```sh
   cd deploy
   test -f .env || install -m 600 .env.example .env
   ```

2. Откройте `.env` в редакторе и задайте `JUDGE_SECRET`. Если пароль уже задан, используйте его.
3. Запустите сервер из папки `deploy` и проверьте состояние контейнера.

   ```sh
   docker compose up -d --build --wait
   docker compose ps
   ```

4. Откройте [главную страницу](http://localhost:8787) и введите пароль организатора. Рейтинговые игры создаются внутри рейтинга и открываются у судьи. Для подготовки турнира откройте **Админку**, добавьте стадию, создайте игры и назначьте рассадку. Ссылка судьи находится на вкладке **Судья** в пульте, а постоянные ссылки OBS — на странице **Эфир**.

## Как остановить сервер

Выполните из папки `deploy`.

```sh
docker compose down
```

Контейнеры остановятся и будут удалены. Турниры, игры и фотографии сохранятся в томе `judge_data`. Для повторного запуска используйте ту же команду `docker compose up -d --build --wait`. Флаги `-v` и `--volumes` у команды `down` удаляют том с базами.

Временная остановка, проверка журналов, подключение с телефона и запуск с HTTPS описаны в [инструкции для оператора](docs/operator.md).
