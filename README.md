# HUD для спортивной мафии

Пульт для оператора, протокол судьи и оверлей для OBS. Игра, настройки и фотографии сохраняются в SQLite на сервере.

## Запуск

Нужен Docker Compose v2. В Windows запустите Docker Desktop в режиме Linux-контейнеров.

1. Скопируйте [judge/.env.example](judge/.env.example) в `judge/.env` и задайте пароль `JUDGE_SECRET`.
2. Из корня проекта выполните:

   ```sh
   cd judge
   docker compose up -d --build --wait
   ```

3. Откройте [пульт](http://localhost:8787/panel) и введите пароль. На вкладке **OBS** скопируйте ссылку в источник «Браузер» с размером 1920×1080. На вкладке **Судья** возьмите ссылку на протокол.

Для остановки выполните `docker compose down` в папке `judge`. Docker сохранит базу. Подключение с телефона, HTTPS и работа с MafiaUniverse описаны в [инструкции для оператора](judge/README.md).
