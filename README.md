# HUD для спортивной мафии

Пульт для оператора, протокол судьи и оверлей для OBS. Игра, настройки и фотографии сохраняются в SQLite на сервере.

## Как запустить сервер

Откройте терминал WSL или Linux в корне проекта. Проверьте, что Docker запущен и команда `docker compose version` работает. Если используете Docker Desktop, включите интеграцию с вашей WSL-системой.

1. Перейдите в папку деплоя и создайте `.env`, если его ещё нет.

   ```sh
   cd deploy
   test -f .env || install -m 600 .env.example .env
   ```

2. Откройте `.env` в редакторе и задайте `JUDGE_SECRET`. Если пароль уже задан, используйте его.
3. Запустите сервер из папки `deploy` и проверьте состояние контейнера.

   ```sh
   docker compose up -d --build --wait
   docker compose ps
   ```

4. При стандартных настройках откройте [пульт](http://localhost:8787/panel) и введите пароль. На вкладке **OBS** скопируйте ссылку в источник «Браузер» с размером 1920×1080. На вкладке **Судья** возьмите ссылку на протокол.

## Как остановить сервер

Выполните из папки `deploy`.

```sh
docker compose down
```

Контейнеры остановятся и будут удалены. Игра и фотографии сохранятся в томе `judge_data`. Для повторного запуска используйте ту же команду `docker compose up -d --build --wait`. Флаги `-v` и `--volumes` у команды `down` удаляют том с базой.

Временная остановка, проверка журналов, подключение с телефона и запуск с HTTPS описаны в [инструкции для оператора](docs/operator.md).
