# Сервер HUD

Быстрый запуск описан в [README проекта](../README.md). Игра и фотографии хранятся в `/data/hud.sqlite` внутри Docker-тома. При обновлении прежнего сервера файлы `game.json` и `photos/` из того же тома импортируются автоматически. Они остаются как резервная копия до миграции.

## Управление

Команды выполняются в папке `judge`.

| Действие | Команда |
|---|---|
| Запуск и обновление после получения кода | `docker compose up -d --build --wait` |
| Остановка | `docker compose down` |
| Журнал | `docker compose logs --tail 100 judge` |

Для резервной копии остановите HUD и сохраните том `judge_data` или файл `hud.sqlite` из него. Флаг `down --volumes` удаляет данные. При запуске через Node.js 24+ база будет в `judge/data/hud.sqlite` или в указанном `DATA_DIR`. Игры из старого браузерного пульта можно перенести кнопкой «Перенести игру на сервер» из прежней версии, пока данные ещё есть в браузере.

## Подключение

- **Телефон в той же Wi-Fi-сети.** В `.env` задайте `JUDGE_PUBLISH=0.0.0.0:8787`. Откройте пульт через IP компьютера, чтобы он сформировал рабочую ссылку для судьи. При необходимости разрешите порт 8787 в брандмауэре частной сети.
- **Публичный сервер.** Используйте HTTPS-прокси с поддержкой WebSocket к `127.0.0.1:8787`. Для встроенного Caddy задайте `DOMAIN` и `COMPOSE_PROFILES=https` в `.env`. Домен должен указывать на сервер, порты 80 и 443 должны быть свободны.
- **OBS.** Ссылка `/hud` показывает сцену, выбранную в пульте. Ссылки на худ и протокол дают доступ к данным игры, поэтому отправляйте их только участникам команды трансляции.

## MafiaUniverse

1. В пульте на вкладке **Игроки** добавьте на панель закладок кнопки «Отправить в HUD» и «Заполнить протокол».
2. Для импорта откройте **Игры** нужного турнира на MafiaUniverse, нажмите «Отправить в HUD» и выберите стол в пульте. Ник для сопоставления можно задать отдельно от ника на худе.
3. Для экспорта откройте редактирование нужной игры на MafiaUniverse, нажмите «Заполнить протокол», войдите в пульт и проверьте заполненные поля. Нажмите «Сохранить» на сайте.
4. Для показа сохранённых итогов используйте блок **Экран худа** на вкладке **Игра**. Результаты отдельной игры загружаются по игре из списка или ссылке, таблица турнира — по ID или ссылке на турнир.

## Тесты

Из корня проекта: `node --test "judge/test/*.test.js"` (Node.js 24+, для браузерных тестов нужен Chrome). Проверка Docker: `bash judge/test/compose.test.sh` (порты 80 и 443 должны быть свободны).
