# Судья с телефона

Судья на телефоне выдаёт роли, ставит фолы и отмечает убитых, заголосованных и удалённых. Команды идут так: телефон → туннель localhost.run → сервер на вашем компьютере → пульт на ноутбуке → OBS. Компьютер, ноутбук и телефон могут находиться в разных сетях.

Этот способ подходит для разового запуска: `start.bat` только пересылает команды, а игра остаётся в браузере на ноутбуке. Чтобы игра не зависела от ноутбука, используйте [постоянный сервер](#установка-на-постоянный-сервер).

## Один раз на компьютере с сервером

1. Установите [Node.js](https://nodejs.org). Клиент `ssh` уже есть в Windows 10 и 11.
2. Скопируйте на этот компьютер папку `judge`.

## Перед каждым турниром

1. На компьютере запустите `start.bat` и не закрывайте его окно. В нём работают и сервер, и туннель.
2. Скопируйте из окна адрес вида `https://....lhr.life`. При каждом запуске он новый.
3. На ноутбуке откройте пульт, на странице «Судья» вставьте адрес и нажмите «Подключить».
4. Отправьте судье ссылку из этого блока. Статус «Судья на связи» значит, что телефон подключился.

## Установка на постоянный сервер

Вместо компьютера и `start.bat` можно использовать VPS. Тогда адрес не меняется, а ссылку судье достаточно отправить один раз. Сервер судьи и худ работают в контейнерах Docker и запускаются сами после перезагрузки. Если Docker на сервере нет, скрипт установит его.

Понадобятся VPS с Ubuntu 24.04 или новее и доступ `root` по SSH. Порты 80 и 443 на сервере должны быть свободны. На сервер попадает код из ветки `main` на GitHub, поэтому сначала запушьте изменения.

### Установка

Подключитесь к серверу и выполните, подставив его IP:

```bash
git clone https://github.com/Impuls3gg/mafia-hud.git /opt/mafia-hud
```

```bash
bash /opt/mafia-hud/judge/server-setup.sh IP_СЕРВЕРА
```

С доменом, у которого запись A указывает на IP сервера, укажите домен вместо IP: тогда запустится ещё и Caddy с HTTPS.

Когда появится «Готово», откройте `адрес-сервера/panel`, войдите с показанным паролем и отправьте судье ссылку из блока «Судья с телефона». Если игра уже есть в пульте из файла, сначала [перенесите её](#перенос-игры-из-файла).

### Обновление

На сервере выполните одну команду. Она скачает новую версию и пересоберёт контейнеры, а адрес, пароль, сертификат и игра сохранятся:

```bash
bash /opt/mafia-hud/judge/update.sh
```

Чтобы сменить адрес, например перейти на домен, укажите его в конце этой команды.

### С компьютера на Windows

`deploy.bat` выполняет установку или обновление сам, заходить на сервер не нужно. Запустите его и введите IP сервера. Новый домен указывайте, только если хотите его поменять.

### Что важно знать

Пароль сервера нужен только пульту: без него на сервере нельзя открыть игру. Судья открывает обычную ссылку, пульт для этого не нужен. Пароль не меняется при обновлениях и показывается после каждой установки или обновления.

Без домена адрес выглядит как `http://IP_СЕРВЕРА`, а соединение не шифруется, поэтому ссылку судьи и пароль сервера можно перехватить в сети. Если посторонний получил ссылку, нажмите «Новая ссылка».

## Пульт на сервере

Пульт разбит на страницы: «Игра» — экран худа, рассадка с ролями и фолами, ночи и номер игры; «Игроки» — список турнира и рассадка из MafiaUniverse; «Судья» — ссылка для судьи с телефона; «Дизайн» — название, цвет, размеры плашек, прозрачность выбывших игроков и превью; «OBS» — связь и ссылки для OBS. Связь с сервером видна в шапке на любой странице. Страница запоминается в адресе, например `адрес-сервера/panel#design`.

На постоянном сервере игра хранится на самом сервере: игроки, роли, ночи, фото и настройки. Пульт открывается по адресу `адрес-сервера/panel` с паролем сервера, с любого устройства и сразу с нескольких.

Если устройство с пультом выключилось, судья продолжает работать, а худ обновляется. Откройте пульт на другом устройстве и продолжайте с того же места.

Если пропала связь с сервером, пульт покажет «Нет связи с сервером». Изменения отправятся, когда связь вернётся, а фото в это время загрузить нельзя. Пароль пульт спрашивает заново в каждой новой вкладке.

Если OBS работает на том же устройстве, стрим при выключении остановится: сервер сохраняет игру, но не заменяет OBS.

### Перенос игры из файла

Это нужно сделать один раз, чтобы не вводить игроков и фото заново.

1. Откройте пульт из файла и на странице «Судья» укажите адрес и пароль сервера. Адрес указывайте вместе с `http://`.
2. Нажмите «Перенести игру на сервер». Игра, которая уже есть на сервере, будет заменена.
3. Откройте `адрес-сервера/panel` и работайте там. Пульт из файла больше не подключается к этому серверу.

Ссылки судьи и OBS остаются прежними. Если OBS показывал худ из файла, замените источники ссылками из пульта: без пульта из файла такой худ не обновляется.

### Рассадка из MafiaUniverse

Пульт на сервере сам рассаживает игроков и ставит номер игры по рассадке турнира на [MafiaUniverse](https://mafiauniverse.org). Рассадка там видна только после входа, поэтому её передаёт закладка из браузера судьи: пароль от MafiaUniverse серверу не нужен.

1. В пульте на странице «Игроки» в блоке «Рассадка из MafiaUniverse» перетащите кнопку «Отправить в HUD» на панель закладок браузера. Это нужно сделать один раз.
2. На MafiaUniverse войдите, откройте турнир и перейдите в раздел «Игры».
3. Нажмите закладку «Отправить в HUD». Откроется пульт: если нужно, введите пароль сервера. Пульт покажет, сколько игр получено.
4. Выберите свой стол. Пульт рассадит первую несыгранную игру стола и поставит её номер «Игра N» — порядковый номер игры за этим столом: тур 3 становится «Игра 3», а первый финал после 14 туров — «Игра 15».

Кнопки «Следующая» и «Предыдущая» и «Рассадить» в списке игр меняют рассадку без возврата на сайт. Если в текущей игре уже есть роли, фолы или ночи, пульт сначала спросит, сбросить ли их. Игроков пульт ищет в списке турнира без учёта регистра, поэтому их фото сохраняются, а новых добавляет сам. У каждого игрока в списке есть поле «ник на MafiaUniverse»: по нему импорт узнаёт игрока, а на худе показывается обычный ник, который можно менять. Импорт заполняет это поле сам. Если игрок уже был в списке под другим ником, впишите его ник на MafiaUniverse вручную, и импорт не заведёт его второй раз.

Нажимайте закладку снова, только если организатор поменял рассадку или добавил туры. Места и номер игры по-прежнему можно менять вручную.

## Худ в OBS через сервер

На постоянном сервере работает и сам худ. Тогда OBS открывает его по ссылке, а не из файла, и не должен быть на одном устройстве с пультом. Команды идут так: пульт или судья → сервер → OBS.

1. В пульте на странице «OBS» в блоке «Худ в OBS через сервер» скопируйте ссылку.
2. В OBS откройте свойства источника «Браузер», снимите галочку «Локальный файл» и вставьте ссылку в поле URL.
3. Проверьте строку «Экраны» в пульте: подключённый экран отмечен точкой.

Худ сам показывает и игру, и экраны победы. Переключайте их кнопками «Игра», «Победа мирных» и «Победа мафии» в блоке «Экран худа» на странице «Игра»: название турнира с анимацией уходит в центр, ночные действия улетают, плашки победившей команды съезжаются в середину ряда, а остальные исчезают. «Новая игра» возвращает худ на игру. Две другие ссылки открывают прежние отдельные экраны победы, если они ещё нужны.

Эти ссылки показывают роли игроков, поэтому не публикуйте их и не показывайте на стриме. Кнопка «Новые ссылки» отключает старые, после чего их нужно заменить в источниках OBS. Без домена данные идут по сети без шифрования.

## Как пользоваться

Страница судьи устроена как протокол игры на MafiaUniverse: таймер речи сверху и таблица игроков с колонками 👍, №, «Игрок», «Фолы», «1 🔫» (первый убиенный) и «Роль».

- **Таймер речи:** нажмите на ник, затем «▶ Речь» — игрок получит слово, и пойдёт отсчёт. Кнопки рядом ставят таймер на паузу, сбрасывают его и переключают длину речи между 60 и 30 секундами. На худе таймер виден вверху по центру, а плашка говорящего обведена.
- **Роли:** выберите роль в последней колонке, номер окрасится в цвет роли. Игрок без роли считается мирным в проверках и на экране победы. Галочка «Скрыть роли» прячет роли и итоги проверок только на этом телефоне, чтобы их не подсмотрели.
- **Фолы и статусы:** «+» добавляет фол, а «−» снимает его, четвёртый фол удаляет игрока. Нажмите на ник, чтобы открыть кнопки «Убит», «Заголосован» и «Удалён». Выбывшие игроки зачёркнуты.
- **Голосование:** как на MafiaUniverse. 👍 выставляет игрока на голосование текущего дня, повторное нажатие или корзина в блоке «Голосование» снимает его. У каждого выставленного число голосов выбирается кнопками 0–10. «Итог голосования»: если лидер один, он покидает стол и отмечается заголосованным; если у нескольких поровну — начинается переголосование между ними; если и там поровну — судья выбирает «Подняли» (стол покидают все) или «Оставили» (никто). «Изменить» отменяет итог и возвращает голосование, «Следующий день» начинает новый день. На худе плашки кандидатов текущего голосования чуть приподняты.
- **Ночные действия:** для каждой ночи выберите игрока в строках «Отстрел», «Шериф» и «Дон». Справа показан итог проверки. Игрок из строки «Отстрел» отмечается убитым, а как только в ночи появляется действие, ниже добавляется следующая.
- **Лучший ход:** как на MafiaUniverse — нажмите ячейку «л.х.» в колонке «1 🔫» у первого убиенного и наберите три номера. Повторное нажатие на номер убирает его, после третьего номера ввод закрывается сам, «Очистить» стирает лучший ход. Пока лучший ход не записан, первым убиенным считается отстрел первой ночи. На худе лучший ход виден над плашкой первого убиенного.
- **Заметки:** свободный текст судьи к игре, сохраняется вместе с игрой.

Дополнительные баллы ставятся на MafiaUniverse. «Новая игра» в пульте очищает выставления, таймер, лучший ход и заметки.

## Если что-то не работает

- Статус «Неверный пароль сервера» значит, что пароль в пульте не совпадает с паролем на сервере. Выполните `bash /opt/mafia-hud/judge/update.sh`, команда покажет верный пароль.
- С `start.bat` пульт на ноутбуке должен быть открыт и подключён к интернету. Без него кнопки у судьи неактивны. На постоянном сервере открытый пульт не нужен.
- Адрес `/panel` работает только на постоянном сервере, потому что без пароля игра не хранится. С `start.bat` используйте пульт из файла.
- Ссылка даёт управление игрой, поэтому передавайте её только судье. Кнопка «Новая ссылка» отключает старую.
- Если туннель оборвался, `start.bat` подключится сам, но адрес может стать другим. Тогда вставьте новый адрес в пульт и заново отправьте ссылку судье.
- Кнопка «Убит» записывает отстрел в текущую ночь и снимает его при повторном нажатии. Номер ночи виден над кнопками у этого игрока.

## Для разработчиков

Код меняется только в `mafia-hud.html`. Правила игры лежат в блоке `<script id="rules">`: его выполняет и сервер, поэтому к странице он обращаться не должен. Потом пересоберите экраны победы:

```bash
node tools/sync-win.js
```

Тесты запускаются из корня репозитория. Нужен Node.js 22 или новее, зависимости ставить не надо:

```bash
node --test "judge/test/*.test.js"
```

Проверки пульта используют Chrome. Если он установлен не в обычную папку, укажите путь в `CHROME_PATH`, иначе они будут пропущены.

Скрипт установки проверяется в Bash на подменённых командах, сервер для этого не нужен:

```bash
bash judge/test/setup.test.sh
```

Установка и обновление целиком проверяются в Linux или WSL с Docker на временном репозитории. Порт 80 должен быть свободен:

```bash
bash judge/test/update.test.sh
```

Контейнеры проверяются в Linux или WSL с Docker. Порты 80 и 443 должны быть свободны:

```bash
bash judge/test/compose.test.sh
```
