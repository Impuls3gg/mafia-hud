# Судья с телефона

Судья на телефоне выдаёт роли, ставит фолы и отмечает убитых, заголосованных и удалённых. Команды идут так: телефон → туннель localhost.run → сервер на вашем компьютере → пульт на ноутбуке → OBS. Компьютер, ноутбук и телефон могут находиться в разных сетях.

## Один раз на компьютере с сервером

1. Установите [Node.js](https://nodejs.org). Клиент `ssh` уже есть в Windows 10 и 11.
2. Скопируйте на этот компьютер папку `judge`.

## Перед каждым турниром

1. На компьютере запустите `start.bat` и не закрывайте его окно. В нём работают и сервер, и туннель.
2. Скопируйте из окна адрес вида `https://....lhr.life`. При каждом запуске он новый.
3. На ноутбуке откройте пульт, в блоке «Судья с телефона» вставьте адрес и нажмите «Подключить».
4. Отправьте судье ссылку из этого блока. Статус «Судья на связи» значит, что телефон подключился.

## Установка на постоянный сервер

Вместо компьютера и `start.bat` можно использовать VPS. Тогда адрес не меняется, а ссылку судье достаточно отправить один раз. Сервер судьи и худ работают в контейнерах Docker и запускаются сами после перезагрузки. Если Docker на сервере нет, скрипт установит его.

Понадобятся VPS с Ubuntu 24.04 или новее и доступ `root` по SSH. Порты 80 и 443 на сервере должны быть свободны. На сервер попадает код из ветки `main` на GitHub, поэтому сначала запушьте изменения.

### Установка

Подключитесь к серверу и выполните, подставив его IP:

```bash
git clone https://github.com/Impuls3gg/mafia-hud.git /opt/mafia-hud
```

```bash
bash /opt/mafia-hud/judge/server-setup.sh IP_СЕРВЕРА
```

С доменом, у которого запись A указывает на IP сервера, укажите домен вместо IP: тогда запустится ещё и Caddy с HTTPS.

Когда появится «Готово», вставьте показанные адрес и пароль сервера в пульт, нажмите «Подключить» и отправьте судье ссылку из блока «Судья с телефона».

### Обновление

На сервере выполните одну команду. Она скачает новую версию и пересоберёт контейнеры, а адрес, пароль и сертификат сохранятся:

```bash
bash /opt/mafia-hud/judge/update.sh
```

Чтобы сменить адрес, например перейти на домен, укажите его в конце этой команды.

### С компьютера на Windows

`deploy.bat` выполняет установку или обновление сам, заходить на сервер не нужно. Запустите его и введите IP сервера. Новый домен указывайте, только если хотите его поменять.

### Что важно знать

Пароль сервера нужен только пульту: без него на сервере нельзя создать игру. Судья открывает обычную ссылку и подключается, когда пульт уже на связи. Пароль не меняется при обновлениях и показывается после каждой установки или обновления.

Без домена адрес выглядит как `http://IP_СЕРВЕРА`, а соединение не шифруется, поэтому ссылку судьи и пароль сервера можно перехватить в сети. Вставляйте адрес в пульт вместе с `http://`. Если посторонний получил ссылку, нажмите «Новая ссылка».

## Худ в OBS через сервер

На постоянном сервере работает и сам худ. Тогда OBS открывает его по ссылке, а не из файла, и не должен быть на одном устройстве с пультом. Команды идут так: пульт → сервер → OBS.

1. В пульте укажите адрес и пароль сервера в блоке «Судья с телефона» и нажмите «Подключить».
2. В блоке «Худ в OBS через сервер» скопируйте ссылку.
3. В OBS откройте свойства источника «Браузер», снимите галочку «Локальный файл» и вставьте ссылку в поле URL. Для экранов победы используйте две другие ссылки.
4. Проверьте строку «Экраны» в пульте: подключённый экран отмечен точкой.

Сам пульт остаётся файлом на вашем устройстве вместе со списком игроков и фото. Он должен быть открыт, иначе экраны покажут последние полученные данные.

Эти ссылки показывают роли игроков, поэтому не публикуйте их и не показывайте на стриме. Кнопка «Новые ссылки» отключает старые, после чего их нужно заменить в источниках OBS. Без домена данные идут по сети без шифрования.

## Как пользоваться

На странице судьи два списка с номером и ником каждого игрока. Нажмите на игрока, чтобы открыть кнопки.

- **Роли:** сначала ролей нет и номера серые. Выберите роль, строка закроется сама, а номер окрасится в цвет роли. Повторное нажатие на роль снимает её. Игрок без роли считается мирным в проверках и на экране победы.
- **Фолы и статусы:** в строке игрока видно число фолов, кнопка «+» добавляет фол, а «−» снимает его. Нажмите на ник, чтобы открыть кнопки «Убит», «Заголосован» и «Удалён». Выбывшие игроки зачёркнуты.
- **Ночные действия:** для каждой ночи выберите игрока в строках «Отстрел», «Шериф» и «Дон». Справа показан итог проверки. Игрок из строки «Отстрел» отмечается убитым, а как только в ночи появляется действие, ниже добавляется следующая.

## Если что-то не работает

- Статус «Неверный пароль сервера» значит, что пароль в пульте не совпадает с паролем на сервере. Выполните `bash /opt/mafia-hud/judge/update.sh`, команда покажет верный пароль.
- Пульт на ноутбуке должен быть открыт и подключён к интернету. Без него кнопки у судьи неактивны.
- Ссылка даёт управление игрой, поэтому передавайте её только судье. Кнопка «Новая ссылка» отключает старую.
- Если туннель оборвался, `start.bat` подключится сам, но адрес может стать другим. Тогда вставьте новый адрес в пульт и заново отправьте ссылку судье.
- Кнопка «Убит» записывает отстрел в текущую ночь и снимает его при повторном нажатии. Номер ночи виден над кнопками у этого игрока.

## Для разработчиков

Код меняется только в `mafia-hud.html`. Потом пересоберите экраны победы:

```bash
node tools/sync-win.js
```

Тесты запускаются из корня репозитория. Нужен Node.js 22 или новее, зависимости ставить не надо:

```bash
node --test "judge/test/*.test.js"
```

Проверки пульта используют Chrome. Если он установлен не в обычную папку, укажите путь в `CHROME_PATH`, иначе они будут пропущены.

Скрипт установки проверяется в Bash на подменённых командах, сервер для этого не нужен:

```bash
bash judge/test/setup.test.sh
```

Установка и обновление целиком проверяются в Linux или WSL с Docker на временном репозитории. Порт 80 должен быть свободен:

```bash
bash judge/test/update.test.sh
```

Контейнеры проверяются в Linux или WSL с Docker. Порты 80 и 443 должны быть свободны:

```bash
bash judge/test/compose.test.sh
```
