# Сервер и проведение игр

Быстрый запуск описан в [README проекта](../README.md). Каталог игр, составы, планы рассадки, итоговые места, общие фотографии и настройки OBS хранятся в `/data/platform.sqlite`. Протоколы, таймеры и настройки отдельных игр хранятся в `/data/games/<id>/hud.sqlite`. При переходе с однопользовательской версии создайте игры и ссылки заново. Исходная база `/data/hud.sqlite` остаётся в томе.

## Проведение и трансляция

1. Войдите на главной под паролем организатора. В разделе **Участники** добавьте игроков по одному, списком или из файла. Отметьте подтверждение и оплату. Раскройте строку участника, чтобы задать ник на MafiaUniverse и загрузить фото. Удаление из состава сохраняет уже заданную рассадку и результаты игр.
2. В разделе **Пульт оператора** выберите игру. Здесь видна готовая рассадка и доступны сцены, ссылки судьи и OBS, экспорт протокола в MafiaUniverse. На вкладке **Судья** скопируйте ссылку на протокол. Рейтинговая игра сразу открывается у судьи. Там он вводит участников в разделе **Рассадка**, затем нажимает **Перемешать** или **Сохранить рассадку**.
3. Судья выбирает победителя, и игра автоматически отмечается как завершённая. Базовые баллы едины для всех турниров: 1 за победу, 0 за поражение или ничью. Таблица учитывает допы и оба вида штрафов и пересчитывается после исправления результата. При равенстве баллов выше игрок с большим числом побед.
4. В разделе **Дизайн OBS** настройте оформление и нажмите **Применить ко всем столам**. Выберите игру, чтобы проверить сохранённые изменения в предпросмотре. Для эфира добавьте в OBS источник **Браузер** с размером 1920 × 1080. Возьмите постоянную ссылку стола и выбирайте игру в разделе **Эфир** на странице турнира.

Турнир открывается на странице **Общая информация**, где можно указать даты, организатора и место проведения. На странице **Игры** можно искать по нику и отключать группировку по турам. Название игры открывает её результат и протокол. Карандаш ведёт к редактированию протокола у судьи.

## Админка турнира

1. Создайте стадии. Укажите число игр на игрока, количество игроков, кратное 10, и коэффициент. Коэффициент стадии умножает итоговые баллы игры после допов и штрафов. Назначьте судей по столам и при необходимости задайте ограничения для пар игроков или игрока и судьи.
2. Выберите стадию и нажмите **Создать игры**. Повторный запуск добавляет только недостающие столы. Каждая игра появляется в списке с номером тура и назначенным судьёй.
3. Нажмите **Создать рассадку**. В автоматическую рассадку попадают подтверждённые игроки. Если мест меньше, чем подтверждённых участников, приоритет получают уже игравшие, затем участники по турнирной таблице. Генератор учитывает ограничения, повторные встречи и позиции. Для швейцарки распределение следующего тура доступно после завершения предыдущего. Начатые и завершённые игры защищены от автоматической перезаписи.
4. Для ручной рассадки откройте **Рассадка отдельной игры** в админке, выберите игру и заполните места. Для пакетного импорта загрузите CSV с четырьмя колонками в порядке «тур, стол, место, ник». Заполните все 10 мест каждого импортируемого стола. Можно указать локальные номера туров стадии или использовать сквозную нумерацию турнира.
5. **Посчитать результат** показывает предварительную таблицу. После завершения игр нажмите **Установить итоговые места**. Если есть финальная стадия, её участники занимают верхние места по итогам финала. Зафиксированную таблицу можно открыть для пересчёта. Если часть игр не состоялась, удалите незавершённые игры и приведите количество игр в стадиях к фактическому.

## Рейтинги

Откройте раздел **Рейтинги** в верхнем меню и создайте рейтинг. Игры добавляются на его странице. Номера присваиваются по порядку внутри рейтинга. Результаты видны в списке. Нажмите на номер игры, чтобы сразу открыть судейский протокол.

## Управление

Команды Docker Compose выполняются в папке `deploy`.

При обновлении существующей установки запустите `bash deploy/update.sh` из корня репозитория. Скрипт использует адрес и пароль из `deploy/.env` и тот же том Docker.

| Действие | Команда |
|---|---|
| Первый запуск, запуск после `down` или обновление кода | `docker compose up -d --build --wait` |
| Временная остановка с сохранением контейнеров | `docker compose stop` |
| Возобновление после `stop` | `docker compose start` |
| Остановка и удаление контейнеров с сохранением данных | `docker compose down` |
| Состояние, включая остановленные контейнеры | `docker compose ps -a` |
| Последние сообщения сервера | `docker compose logs --tail 100 judge` |

Если Caddy был запущен флагом `--profile https` и профиль не задан в `.env`, укажите этот флаг и при остановке. Например, `docker compose --profile https down` остановит и HUD, и Caddy.

Для резервной копии остановите сервер и сохраните весь том `judge_data`. При запуске через Node.js 24+ данные находятся в папке `data/` проекта или в указанном `DATA_DIR`.

## Подключение

- **Телефон в той же Wi-Fi-сети.** В `.env` задайте `JUDGE_PUBLISH=0.0.0.0:8787`. Откройте пульт через IP компьютера, чтобы он сформировал рабочую ссылку для судьи. При необходимости разрешите порт 8787 в брандмауэре частной сети.
- **Публичный сервер.** Используйте HTTPS-прокси с поддержкой WebSocket к `127.0.0.1:8787` и передачей исходного заголовка `Host`. Для встроенного Caddy задайте `DOMAIN`, `COMPOSE_PROFILES=https` и `HUD_TRUST_CADDY=1` в `.env`. Если включено доверие Caddy, держите прямой порт HUD на loopback. Домен должен указывать на сервер, порты 80 и 443 должны быть свободны.
- **Установка по IP.** Скрипт включает HTTP только для loopback или частного IPv4 и привязывает порт к указанному адресу. Используйте этот режим в доверенной сети. Скрипт хранит пароль в защищённом `deploy/.env`.
- **OBS и судья.** Ссылки OBS на странице турнира предназначены для команды трансляции. Ссылку из вкладки **Судья** отправляйте назначенному судье.

## Первый запуск с HTTPS

Для новой установки на Ubuntu укажите домен в команде из корня клона. Домен должен вести на сервер, а порты 80 и 443 должны быть свободны.

```sh
sudo bash deploy/server-setup.sh hud.example.com
```

Подставьте свой домен вместо `hud.example.com`. Скрипт создаст `deploy/.env` и запустит приложение с Caddy. Откройте главную страницу своего домена и используйте пароль из поля `JUDGE_SECRET` в `deploy/.env`. Для остановки перейдите в `deploy` и выполните `docker compose down`.

## MafiaUniverse

1. В пульте на вкладке **Игроки** добавьте на панель закладок кнопки «Отправить в HUD» и «Заполнить протокол».
2. Для импорта откройте **Игры** нужного турнира на MafiaUniverse и нажмите «Отправить в HUD». В пульте выберите стол и нажмите **Рассадка в админке** рядом с нужной игрой. Проверьте сопоставление участников и нажмите **Сохранить рассадку**. Ник для сопоставления можно задать отдельно от ника на худе.
3. Для экспорта откройте редактирование нужной игры на MafiaUniverse, нажмите «Заполнить протокол», войдите в пульт и проверьте заполненные поля. Нажмите «Сохранить» на сайте.
4. Для показа сохранённых итогов используйте блок **Экран худа** на вкладке **Игра**. Результаты отдельной игры загружаются по игре из списка или ссылке, таблица турнира — по ID или ссылке на турнир.

## Тесты

Из корня проекта выполните `npm ci` и `npm test` (Node.js 24+, для браузерных тестов нужен Chrome). Проверка Docker: `bash test/compose.test.sh` (порты 80 и 443 должны быть свободны).
